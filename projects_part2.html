Projects

I'm just starting out in web development, so these are the real pieces of this portfolio site itself — each one built to practice a specific front-end skill.

This portfolio site

Tools used

HTML5, hand-written CSS3 (custom properties, CSS Grid, mobile-first media queries), no frameworks.

What it does

A four-page personal site — Home, Projects, About/Contact, and an Interaction Log — built from a single shared stylesheet. It's responsive from a 320px mobile layout up through a 1200px desktop breakpoint, and includes accessibility basics like a skip link, visible focus states, and a mobile nav menu that's fully keyboard-operable.

Interaction Log

Tools used

Vanilla JavaScript (DOM manipulation, event listeners).

What it does

Three self-contained widgets built to practice core JavaScript: a button that randomly pulls a new line of text, a text input that changes weight and color live as you type, and a punch-list app where you can add, mark done, and remove items — no page reload, no framework.

GitHub profile card + contact form

Tools used

JavaScript Fetch API, form validation, ARIA attributes.

What it does

On the About page, a live GitHub profile card is pulled with fetch() and includes error handling if the request fails. The contact form next to it validates each field — including a proper email-format check — and reports errors and success messages in a way screen readers announce automatically.
